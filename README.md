# Portfólio — Marcos Ryan Oliveira Porto

Portfólio pessoal em **HTML, CSS e JavaScript**, com apresentação, competências, estudos de caso e galerias de imagens dos projetos.

## O que construí

- Apresentação como desenvolvedor full stack em formação e estudante de ADS no IFNMG.
- Retrato com fundo transparente e layout adaptado para computador e celular.
- Estudos de caso em primeira pessoa para Chico Burguer, Barba & Hora e Atlética Maccoloco.
- Galerias locais com legendas, botões, navegação por setas e fechamento com Escape.
- Links para GitHub e LinkedIn.

## Executar

Abra `index.html` ou execute:

```sh
python -m http.server 8000
```

Acesse http://localhost:8000. Não exige dependências ou build. As fontes do Google são opcionais: sem conexão, o navegador usa a fonte alternativa.

## Estrutura

`index.html` contém a estrutura e os links. `style.css` reúne os estilos e as regras responsivas. `app.js` contém os estudos de caso, dados das galerias e interações. `assets/` contém o retrato e as capturas dos projetos.

## Verificação

Na entrega foram conferidos os estudos de caso, as três galerias, os links profissionais e o layout em largura de 390 px, sem rolagem horizontal. Isso não substitui testes em aparelhos físicos.
