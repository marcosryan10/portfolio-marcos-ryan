# Portfólio — Marcos Ryan Oliveira Porto

## Executar

Abra `index.html` ou execute:

```sh
python -m http.server 8000
```

## Estrutura

`index.html` contém a estrutura e os links. `style.css` reúne os estilos e as regras responsivas. `app.js` contém os estudos de caso, dados das galerias e interações. `assets/` contém o retrato e as capturas dos projetos.

As imagens de pessoas, marcas e projetos são apresentadas como parte do portfólio e não devem ser reutilizadas sem autorização dos titulares.
